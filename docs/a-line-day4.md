# A 线冲刺第 4 天：分享卡片与公共日历读取

更新日期：2026-10-05。接续 [第三天交接说明](a-line-day3.md)。本日完成本地实现和验证；沿用此前安排，云函数部署、云端索引和真机验收由用户处理。

## 本地已实现

- `ScheduleManager.getShareCard({ matchId })`：通过云端身份确认本队队长，允许 pending/confirmed/help/tbd；取消、无需跟场、待结算、已归档、到达 endTime 的比赛返回 409。跨队返回 403，不存在返回 404。
- 返回 `{ title, path }`；标题含项目、队伍、对手和北京时间，TBD 明确标记“时间待定”。路径始终指向 respond，matchId 编码；红态队长分享仍走 respond，不复用部员求助卡片。
- 表单进入编辑、保存成功、修改成功及返回页面时预加载分享配置；按钮使用 `open-type="share"`，未完成时禁用，回调同步读取缓存。分享网络失败提供独立重试，不把保存成功误判为失败。
- 草稿变更、保存/取消、重新加载、隐藏/卸载及再发布一场均使缓存失效。请求序号丢弃旧响应，检查当前身份和结束时间；无有效缓存时隐藏分享菜单，回调被直接触发时仅返回首页。草稿须先保存才能分享。
- 新增独立部署包 `CalendarManager`，首版只实现 `getCalendar/getMatchDetail`，不查询用户身份或跟场记录。
- `getCalendar({ fromTs, toTs })` 校验有效毫秒整数和顺序，采用 `[fromTs, toTs)` 半开区间。普通比赛按开始时间及 ID 正序，保留取消标记和已归档项；TBD 独立查询，不受日期窗口限制，排除取消/归档项，按更新时间倒序及 ID 正序。
- 每批 100 条查询，覆盖超出云数据库默认返回上限的数据；已归档比赛按 ID 批量合并比分、结果和 `hasMedia`。缺归档时不伪造比分；重复归档及数据库异常返回 500。
- 公开 DTO 仅返回白名单展示字段，检查字段类型，使用 Asia/Shanghai 格式化时间。隐藏全部 openid、版本、幂等缓存、嵌套原始数据和媒体链接；详情允许查看已取消/归档比赛。
- 首页公共日历界面仍留第 5 天；`getMediaLink` 留归档收尾阶段。
