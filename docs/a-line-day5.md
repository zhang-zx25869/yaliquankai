# A 线冲刺第 5 天：首页公共日历

更新日期：2026-10-06。接续 [第四天交接说明](a-line-day4.md)。完成本地实现与验证；云端部署、索引和真机验收沿用此前安排，由用户处理。

## 本地已实现

- 首页接入 `CalendarManager.getCalendar/getMatchDetail`，移除公共赛程占位。公开查询与静默登录并行，未绑定或登录失败时仍能浏览；队长额外保留发布、管理入口，点击时重新检查当前角色。
- 日历按北京时间计算 `[fromTs, toTs)`：默认今天零点至下月一日零点；点击某日查询当天；上一月、下一月、月份选择器和“查看整月”查询整月。“今天及后续”返回当前月的今天至月底，重新进入页面会重新计算今天。
- 七列月历标出今日、选中日期及查询范围。赛程按云端顺序展示，保留取消项和归档比分；时间待定区域独立展示，并明确不受日期窗口限制。
- 复用 `match-detail-card`，卡片摘要显示时间、地点与已有比分；展开时重新读取最新详情，读取成功后显示正文。点击同一卡片收起，切换卡片只保留一场展开。详情失败可独立重试或刷新列表，404 明确提示比赛已不存在。
- 共用卡片优先显示“已归档”，避免已归档比赛仍显示“待结算”；取消标记优先于归档。兼容 `confirmerNickname` 和既有 `confirmerName`，清空比赛时同步清除旧状态元信息。
- 首页不传管理操作开关，所有角色浏览相同公开赛程；不请求媒体链接，媒体入口仍留收尾阶段。
- 列表支持加载、空态、错误重试、下拉刷新、返回刷新。列表与详情分别用请求序号隔离旧响应；更换范围或刷新会清空旧列表并收起详情，隐藏/卸载时使列表、详情和身份回调失效。旧请求不会覆盖新数据或提前结束新一轮刷新提示。
